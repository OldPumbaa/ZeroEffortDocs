# ZeroEffortDocs (ZED)

Гибкий документооборот для компаний: шаблоны, поля, документы. Модули (кадры, архив) подключаются отдельно. Локально или на сервере — один и тот же бинарник.

Это не 1С. Схема документа задаётся формой, а не «конфигуратором».

## Сейчас

- Запуск локального сервера, интерфейс в браузере
- **Импорт документа** — основной путь: простой редактор, свои поля, из них собирается форма
- Повторная регистрация уже идёт по этой форме
- Исходный файл (скан, PDF, Word) хранится рядом с записью
- Модули кадры/архив можно включить заранее — сами появятся следующими шагами

Полноценный Word-редактор, печать и десктоп-обёртка — позже.

## Запуск

Нужны [Rust](https://rustup.rs/) (stable) и браузер.

**В VS Code это Run and Debug, не build task.**

| Как | Что делает |
|-----|------------|
| **F5** (Run and Debug, конфигурация **ZED**) | Собирает `zed.exe` и поднимает сервер под отладчиком. Штатный способ разработки. |
| **Ctrl+F5** | То же, без брейкпоинтов |
| **Ctrl+Shift+B** (build task `cargo: build`) | Только компиляция. Сервер не стартует. |
| `cargo run` в терминале | Запуск без отладчика, браузер открывается сам |

После F5 зайдите на [http://127.0.0.1:4748](http://127.0.0.1:4748) — конфигурация **ZED** специально с `--no-open`, чтобы не мешать отладке. **ZED + браузер** откроет вкладку сама.

Данные: `./data/zed.sqlite`, файлы импорта: `./data/files/`.

```bash
zed --bind 127.0.0.1:4748
zed --bind 0.0.0.0:4748          # доступ по сети / сервер
zed --data-dir D:\zed-data
zed --no-open                    # не трогать браузер
```

`ZED_BIND`, `ZED_DATA_DIR`, `ZED_NO_OPEN=1`, `RUST_LOG=zed=debug`.

> На `0.0.0.0` пока нет логина. В интернет так не выставлять.

Отладчик: расширение [C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools). Toolchain MSVC пишет PDB, его читает `cppvsdbg`, не LLDB.

## Стек (почему так)

| Слой | Выбор | Зачем |
|------|--------|--------|
| Сервер | Rust, Axum | Один бинарник: ноутбук делопроизводителя или сервер компании |
| База | SQLite | Файл рядом с программой, бэкап = скопировать `data/` |
| UI | Браузер, без сборки | Не тащим Chromium. Позже то же UI можно обернуть в Tauri (системный WebView) |
| Модули | Флаги в базе | Кадры и архив не вшиты насильно |

Electron отклонён: тащит Chromium. Node-only отклонён: поиск по архиву и один файл на установку проще делать в Rust. Подробнее — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Замысел продукта — [docs/VISION.md](docs/VISION.md).

# Замысел ZED

ZeroEffortDocs — документооборот для делопроизводителя: загрузил существующие бумаги, отметил на листе что меняется, дальше заполняет короткую форму вместо поиска по договору.

## Принципы

1. **Лист и форма — одно целое.** Шаблон выглядит как страница. На ней помечают места (ФИО, дата, номер). Справа из этих мест собирается форма.
2. **Импорт как есть.** Приказ из компании открывается в простом редакторе. Выделили фрагмент — это поле. Следующий такой документ заполняется формой, а не скроллом.
3. **Модули по желанию.** На мастере и в настройках. Кадры и архив пока «скоро», но галочка уже сохраняется.
4. **Один процесс.** Браузер локально, тот же бинарник на сервере, позже окно вокруг localhost.

## Модули

| id | Что это | Когда |
|----|---------|--------|
| `core` | Компания, шаблоны-листы, документы, история. Всегда. | Сейчас |
| `employees` | Кадровая база. | Позже, флаг уже есть |
| `archive` | Старые файлы + поиск. | Позже, флаг уже есть |

## Как устроен документ

1. Первый вход — мастер: название компании и модули.
2. **Создать → новый документ:** чистый лист. Пишете как в Word, выделяете места, справа настраиваете поле: вписать обязательно / дата при создании / номер по порядку.
3. **Создать → по шаблону:** заполняете форму, лист собирается сам (дата и номер подставляются).
4. **Импорт шаблона:** файл как есть, текст из `.txt` на лист, дальше те же поля.

Поля будем наращивать. Сейчас три рабочих режима, которые закрывают приказ о приёме.

## Что пока простое

- Редактор — лист, не полный Word
- `.docx` читаем как текст; переменные в файле — `{{fio}}`, `{{date}}`, `{{num}}`
- PDF пока не разбираем
- Нумерация — счётчик на шаблон, без серий и префиксов
